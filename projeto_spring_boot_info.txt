2. RESUMO DAS ALTERAÇÕES REALIZADAS (CAMPOS: E-MAIL E NOTA DO ENADE)
--------------------------------------------------------------------------------

Foram adicionados com sucesso os campos de 'E-mail' e 'Nota do ENADE' em todas as camadas da aplicação:

2.1. Modelo Java (br.com.gerenciamento.model.Aluno):
   - Inclusão do campo 'email' (String) com validações:
     * @Column(name = "email")
     * @NotBlank(message = "O e-mail não pode ser vazio")
     * @Email(message = "Insira um e-mail válido")
     * @NotNull(message = "O e-mail é obrigatório")
   - Inclusão do campo 'notaEnade' (Double) com validações:
     * @Column(name = "nota_enade")
     * @NotNull(message = "A nota do ENADE é obrigatória")
     * @Min(value = 0, message = "A nota do ENADE não pode ser menor que 0")
     * @Max(value = 100, message = "A nota do ENADE não pode ser maior que 100")
   - Implementação de todos os Getters e Setters (getEmail, setEmail, getNotaEnade, setNotaEnade).

2.2. Camada de Visualização (Thymeleaf / HTML):
   - 'formAluno.html' (Cadastro de Alunos):
     * Adicionado campo de entrada de texto e validação para Email do Aluno.
     * Adicionado campo numérico (0 a 100, step 0.01) para Nota do ENADE.
   - 'editar.html' (Edição de Alunos):
     * Adicionados os campos de edição para Email e Nota do ENADE.
   - 'listAlunos.html' (Listagem Geral):
     * Adicionadas as colunas 'Email' e 'Nota ENADE' na tabela de alunos cadastrados.
   - 'alunos-ativos.html' (Filtro Ativos):
     * Adicionadas as colunas 'Email' e 'Nota ENADE'.
   - 'alunos-inativos.html' (Filtro Inativos):
     * Adicionadas as colunas 'Email' e 'Nota ENADE'.
   - 'pesquisa-resultado.html' (Busca):
     * Adicionadas as colunas 'Email' e 'Nota ENADE' nos resultados da busca por nome.

2.3. Banco de Dados MySQL (Script Docker - init/01-init.sql):
   - Schema: academyspring
   - Tabela Aluno com: id, nome, email, matricula, nota_enade, curso, status, turno.
   - Tabela Usuario para autenticação.
   - Carga inicial com registros de teste contendo e-mail e notas do ENADE.

3. EXECUÇÃO 100% VIA DOCKER (BANCO + SERVIDOR WEB)
--------------------------------------------------------------------------------

Tudo roda automaticamente no Docker sem necessidade de instalar MySQL ou Java manualmente:

Para iniciar todos os serviços (MySQL + phpMyAdmin + Servidor Spring Boot):
- Dê um duplo-clique no arquivo 'iniciar.bat' (ou execute: docker compose up -d)

Para parar os serviços:
- Dê um duplo-clique no arquivo 'parar.bat' (ou execute: docker compose down)

Endereços de Acesso:
- Aplicação Web Spring Boot: http://localhost:8082
- phpMyAdmin (Painel do Banco): http://localhost:8081
- Porta do MySQL: localhost:3306 (user: root, senha: root)
