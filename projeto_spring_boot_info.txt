2. NOVA FUNCIONALIDADE IMPLEMENTADA: TELA DE ALUNOS POR CURSO COM FILTRO
--------------------------------------------------------------------------------
Conforme solicitacao, foi criada uma tela dedicada para exibir os alunos matriculados
separados por Curso, com destaque para Matricula e Nome, e filtro por qualquer um dos cursos:
[ADMINISTRACAO, INFORMATICA, CONTABILIDADE, ENFERMAGEM, BIOMEDICINA OU DIREITO].

2.1. Camada de Repositorio (AlunoRepository.java):
   - Adicao do metodo:
     List<Aluno> findByCurso(Curso curso);
   - Permite consultas diretas filtradas pelo enum do curso solicitado.

2.2. Camada de Controle (AlunoController.java):
   - Novo endpoint mapeado:
     @GetMapping("/alunos-por-curso")
   - Parametro opcional: 'curso' (ex: ?curso=INFORMATICA)
   - Funcionalidades do Controller:
     * Quando nenhum filtro e aplicado (ou 'TODOS'): monta um mapa ordenado agrupando
       todos os alunos separados por cada um dos 6 cursos de graduacao.
     * Quando um curso especifico e selecionado: retorna a lista exclusiva dos alunos
       daquele curso juntamente com a contagem total de matriculados.

2.3. Camada de Visao (Thymeleaf / HTML / Bootstrap):
   - Nova pagina: 'alunos-por-curso.html'
     * Barra de filtro superior com botoes rapidos (badges interativos) para cada curso:
       [Todos os Cursos], [Administracao], [Informatica], [Contabilidade], [Enfermagem], [Biomedicina], [Direito].
     * Seletor dropdown (combobox) permitindo escolher o curso e clicar em 'Aplicar Filtro'.
     * Exibicao em destaque da MATRICULA (tag estilizada monospace) e do NOME DO ALUNO,
       alem de status (Ativo/Inativo), turno, email, nota ENADE e botoes de acao (Editar e Remover).
     * Visualizacao separada em cards por curso quando nenhum filtro especifico esta selecionado.
   - Atualizacao do Cabecalho ('fragmentos.html'):
     * Inclusao do link direto 'Alunos por Curso' no menu de navegacao superior com icone tematico.
   - Atualizacao da tela 'filtroAlunos.html':
     * Inclusao do card tematico 'Alunos Separados por Curso' com imagem e botao de acesso direto.
   - Atualizacao da tela inicial ('index.html'):
     * Inclusao do botao de atalho 'ALUNOS POR CURSO' na tela principal.

2.4. Banco de Dados e Carga Inicial (init/01-init.sql):
   - Inseridos registros de exemplo contemplando todos os 6 cursos do enum, garantindo
     dados para teste de Administracao, Informatica, Contabilidade, Enfermagem, Biomedicina e Direito.

3. COMO EXECUTAR O PROJETO (VIA DOCKER OU MANUALMENTE)
--------------------------------------------------------------------------------

3.1. Execucao 100% automatizada via Docker (Recomendado):
   Na pasta raiz do projeto:
   - Para iniciar todos os servicos (Banco MySQL + phpMyAdmin + Servidor Spring Boot):
     Execute: docker compose up -d (ou clique duas vezes em 'iniciar.bat')
   - Para parar os servicos:
     Execute: docker compose down (ou clique duas vezes em 'parar.bat')

   Enderecos de Acesso:
   - Sistema Web Spring Boot: http://localhost:8082
   - Tela direta da nova funcionalidade: http://localhost:8082/alunos-por-curso
   - phpMyAdmin (Gerenciador MySQL): http://localhost:8081
   - Conexao direta MySQL: localhost:3306 (user: root, senha: root, banco: academyspring)

3.2. Execucao Local (caso possua Maven e Java 11+ instalados na maquina):
   cd gerenciamento-alunos-crud-springboot
   mvn spring-boot:run
