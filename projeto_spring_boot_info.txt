1. RESUMO DAS ALTERAÇÕES REALIZADAS (CAMPOS: E-MAIL E NOTA DO ENADE)
--------------------------------------------------------------------------------

Foram adicionados com sucesso os campos de 'E-mail' e 'Nota do ENADE' em todas as camadas da aplicação:

1.1. Modelo Java (br.com.gerenciamento.model.Aluno):
   - Inclusão do campo 'email' (String) com anotações de validação:
     * @Column(name = "email")
     * @NotBlank(message = "O e-mail não pode ser vazio")
     * @Email(message = "Insira um e-mail válido")
     * @NotNull(message = "O e-mail é obrigatório")
   - Inclusão do campo 'notaEnade' (Double) com anotações de validação:
     * @Column(name = "nota_enade")
     * @NotNull(message = "A nota do ENADE é obrigatória")
     * @Min(value = 0, message = "A nota do ENADE não pode ser menor que 0")
     * @Max(value = 100, message = "A nota do ENADE não pode ser maior que 100")
   - Implementação de todos os Getters e Setters correspondentes (getEmail, setEmail, getNotaEnade, setNotaEnade).

   - 'formAluno.html' (Cadastro de Alunos):
     * Adicionado campo de entrada de texto e validação para Email do Aluno.

   - 'editar.html' (Edição de Alunos):
     * Adicionados os campos de edição para Email e Nota do ENADE.
   - 'listAlunos.html' (Listagem Geral):
     * Adicionadas as colunas 'Email' e 'Nota ENADE' na tabela de alunos cadastrados.
   - 'alunos-ativos.html' (Filtro Ativos):
     * Adicionadas as colunas 'Email' e 'Nota ENADE'.
   - 'alunos-inativos.html' (Filtro Inativos):
     * Adicionadas as colunas 'Email' e 'Nota ENADE'.
   - 'pesquisa-resultado.html' (Busca):
     * Adicionadas as colunas 'Email' e 'Nota ENADE' nos resultados da busca por nome.

1.3. Banco de Dados MySQL (Script de Inicialização Docker - init/01-init.sql):

     * id INT AUTO_INCREMENT PRIMARY KEY

2. CONFIGURAÇÃO E EXECUÇÃO DO BANCO DE DADOS NO DOCKER
--------------------------------------------------------------------------------

O banco de dados roda 100% via Docker e Docker Compose, eliminando a necessidade de instalar MySQL localmente no computador.

Para iniciar os containers (MySQL 8.0 e phpMyAdmin):
- Opção A (Windows Explorer): Dê um duplo-clique no arquivo 'iniciar.bat'
- Opção B (Linha de comando):
  docker compose up -d

Para parar os containers:
- Opção A (Windows Explorer): Dê um duplo-clique no arquivo 'parar.bat'
- Opção B (Linha de comando):
  docker compose down

Portas e Serviços:
- MySQL Server: localhost:3306
  * Database: academyspring
  * Usuário: root
  * Senha: root
- phpMyAdmin (Interface Web do Banco): http://localhost:8080
  * Servidor: mysql (ou localhost)
  * Usuário: root
  * Senha: root

3. COMO EXECUTAR O PROJETO SPRING BOOT
--------------------------------------------------------------------------------

3.1. No Eclipse IDE:
   1. Abra o Eclipse.
   2. Vá em File -> Import... -> Maven -> Existing Maven Projects.
   3. Selecione a pasta descompactada do projeto ('gerenciamento-alunos-crud-springboot').
   4. Clique em Finish e aguarde o download das dependências do Maven.
   5. Clique com o botão direito na classe 'GerenciamentoAlunosApplication.java' -> Run As -> Java Application (ou Spring Boot App).

3.2. No VS Code ou IntelliJ IDEA:
   1. Abra a pasta 'gerenciamento-alunos-crud-springboot' na IDE.
   2. Execute o arquivo 'GerenciamentoAlunosApplication.java' ou utilize o painel Spring Boot Dashboard.

3.3. Pela Linha de Comando (Maven Wrapper):
   - Windows:
     .\mvnw.cmd spring-boot:run
   - Linux/Mac:
     ./mvnw spring-boot:run
